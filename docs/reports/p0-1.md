# P0-1 Implementation Report — Empty `directory` Guard + 1.0.9 Bump

- **Issue:** https://github.com/Heretek-AI/opencode-harness/issues/4
- **Branch:** `main` (working tree, uncommitted)
- **Version:** 1.0.8 → 1.0.9

## Summary

Host `@opencode/cli@2.0.32` passes `setup({ directory: "" })`. The
`inferredRoot` chain in `setupOpenCodeV2Harness` used `??` only, which
skips `null`/`undefined` but lets `""` through into
`resolveHarnessOptions({ rootDir: "" })`, which correctly throws
fail-closed. Fixed by adding a `pick()` guard that treats `""` and
whitespace-only strings as absent while preserving all other behavior.

## Files changed

1. **`src/index.ts`** — added `pick()` guard in `setupOpenCodeV2Harness`:
   ```ts
   const pick = (v: unknown): string | undefined =>
     typeof v === "string" && v.trim() !== "" ? v : undefined;
   const inferredRoot =
     pick(ctx?.directory) ??
     pick(ctx?.worktree) ??
     pick(ctx?.location?.directory) ??
     pick(ctx?.location?.worktree) ??
     process.cwd();
   ```
   - `pick()` returns `undefined` for non-strings, `""`, `"   "`,
     `"\t\n "`; returns the original string unchanged otherwise
     (only the emptiness test trims).
   - `process.cwd()` fallback remains last.
   - `resolveHarnessOptions({ rootDir: inferredRoot, ...merged })`
     merge order unchanged; `resolveHarnessOptions` itself untouched
     (direct `""` / `"   "` calls still throw fail-closed).

2. **`src/version.ts`** — `HARNESS_RELEASE_VERSION` `"1.0.8"` → `"1.0.9"`.

3. **`package.json`** — `"version"` `"1.0.8"` → `"1.0.9"` (matches
   `src/version.ts`, asserted by `test/bootstrap.test.ts`).

4. **`test/p0-1-empty-directory.test.ts`** (new, 9 tests) — exercises the
   REAL `setupOpenCodeV2Harness` with a minimal fake host:
   - `setup({ directory: "" })` no-throw, `workspaceRoot === process.cwd()`
   - `setup({ directory: "   " })` no-throw, falls back to `process.cwd()`
   - `setup({ worktree: "" })` no-throw
   - `setup({ location: { directory: "" } })` no-throw
   - `setup({ location: { worktree: "   " } })` no-throw
   - `setup({ directory: "", worktree: "/tmp" })` resolves to `"/tmp"`
   - `setup({ directory: "\t\n " })` whitespace-only falls back to cwd
   - `resolveHarnessOptions({ rootDir: "" })` still throws fail-closed
   - `resolveHarnessOptions({ rootDir: "   " })` still throws fail-closed
